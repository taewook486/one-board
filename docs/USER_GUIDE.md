## 1. 시작하기

### One Board는 무엇인가요?

One Board는 현대적인 커뮤니티 게시판 플랫폼입니다. 사용자는 게시글을 작성하고, 다른 사용자들과 소통할 수 있습니다.

### 웹사이트 접속

- **URL**: `http://localhost:3000` (개발 환경) 또는 배포된 주소
- **필요 권한**: 없음 (공개 게시판)

## 2. 회원가입

### 회원가입 방법

1. 상단 메뉴의 **[회원가입]** 버튼 클릭
2. 아래 정보를 입력합니다:
   - **아이디**: 사용할 아이디 (4-20자)
   - **비밀번호**: 8자 이상
   - **닉네임**: 다른 사용자들에게 표시될 이름 (2-20자)
   - **이메일**: (선택사항)

3. [회원가입하기] 버튼 클릭

### 입력 규칙

- **아이디**:
  - 영문 소문자, 숫자, 밑줄(_), 하이픈(-)만 사용 가능
  - 4-20자 길이 제한
  - 이미 사용 중인 아이디는 불가

- **비밀번호**:
  - 최소 8자 이상
  - 영문 대소문자, 숫자, 특수문자 포함

- **닉네임**:
  - 2-20자 길이 제한
  - 특수문자 사용 불가 (일부 허용)

- **이메일**:
  - 유효한 이메일 형식
  - 선택사항이지만 비밀번호 찾기에 사용

### 가입 절차

1. 아이디 중복 확인 → 자동 검증
2. 닉네임 중복 확인 → 자동 검증
3. 이메일 중복 확인 → 자동 검증
4. 회원 정보 저장 → 자동 로그인 및 홈으로 이동

### 비밀번호 분실

가입 시 이메일을 입력하셨다면, 비밀번호를 잊어버렸을 때 찾을 수 있습니다.

1. 로그인 페이지의 **[비밀번호 찾기]** 링크 클릭
2. 가입 시 입력한 이메일 주소 입력
3. 이메일로 비밀번호 재설정 링크 수신 (현재는 콘솔에 표시)
4. 링크를 통해 새 비밀번호 설정

## 3. 로그인

### 로그인 방법

1. 상단 메뉴의 **[로그인]** 버튼 클릭
2. 아이디와 비밀번호 입력
3. **[로그인]** 버튼 클릭

### 로그인 유지

- **세션 기간**: 브라우저를 닫으면 세션 종료
- **자동 로그인**: 로그인 상태 유지 (7일)
- **로그아웃**: 로그인 후 자동으로 로그아웃

---

## 4. 게시글 작성

### 게시글 작성 방법

1. **로그인**: 로그인 필요
2. 게시판 선택 → 게시판 목록에서 원하는 게시판 클릭
3. **[글쓰기]** 버튼 클릭
4. 게시글 작성 폼 표시

### 글쓰기 기본 구성

1. **제목**: 게시글 제목 입력 (1-255자)
2. **내용**: 에디터를 사용하여 내용 작성
3. **카테고리**: (선택사항) 게시판에 설정된 카테고리 선택
4. **에디터 기능**:
   - **텍스트 서식**: 굵게(B), 기울임(I), 취소선(S)
   - **제목 서식**: 제목 1~3 단계
   - **리스트**: 글머리 목록, 번호 매기기
   - **인용구**: 인용구 블록
   - **코드 블록**: 프로그래밍 코드 블록
5. **이미지 첨부**: (선택사항) 최대 10개, 각 5MB

### 글쓰기 옵션

- **공지사항**: 관리자 권한 필요
- **고정**: 관리자 권한 필요
- **비밀글**: 체크하면 로그인한 사용자만 조회 가능

### 이미지 첨부 방법

1. 에디터 상단의 🖼️ 버튼 클릭
2. 이미지 파일 선택 (최대 5MB)
3. 첨부된 이미지는 에디터 커서 위치에 삽입됨

---

## 5. 게시글 조회 및 검색

### 게시글 목록 조회

1. **게시판 선택**: 상단 메뉴에서 게시판 선택
2. **정렬 옵션**:
   - 최신순 (기본)
   - 조회순
   - 추천순
3. 게시글 목록 표시

### 게시글 검색

1. **검색 메뉴**: 상단의 🔍 검색 버튼 클릭
2. **검색 조건**:
   - **검색어**: 제목, 내용에서 검색
   - **게시판**: 특정 게시판으로 검색 (선택사항)
   - **카테고리**: 카테고리로 검색 (선택사항)
   - **기간**: 특정 기간 내 게시글 검색 (선택사항)
3. **검색 실행**: 검색 버튼 클릭

### 게시글 상세 보기

1. 게시글 제목 클릭
2. 게시글 내용 표시
3. 첨부된 파일 목록
4. 댓글 섹션
5. 작성자, 작성일, 조회수, 추천수 표시

### 게시글 수정/삭제

- **수정**: 자신의 게시글은 수정 가능
- **삭제**: 자신의 게시글은 삭제 가능 (단, 관리자 삭제 권한 있음)

## 6. 댓글 작성

### 댓글 작성 방법

1. 게시글 상세보기 페이지 접속
2. 댓글 입력 폼 표시

### 댓글 작성 규칙

1. **내용**: 댓글 내용 입력 (최대 1000자)
2. **비밀 댓글**: 체크하면 작성자와 관리자만 확인 가능
3. **대댓글**: 기존 댓글의 [답글] 버튼 클릭하여 작성

### 댓글 기능

- **좋아요**: 댓글의 👍 버튼 클릭
- **수정**: 작성 후 수정 가능
- **삭제**: 자신의 댓글 삭제 가능

---

## 7. 프로필 관리

### 프로필 페이지 접근

1. **상단 메뉴**: 사용자 이름 → [프로필] 클릭
2. **프로필 페이지**: 개인 정보 설정

### 프로필 설정 항목

1. **프로필 이미지**:
   - 클릭하여 이미지 파일 선택
   - 최대 5MB, 이미지 파일만 가능
   - 자동으로 원형으로 잘라서징

2. **개인 정보**:
   - **닉네임**: 표시 이름 수정 (2-20자)
   - **이메일**: 이메일 주소 수정 (선택사항)
   - **이름**: 실명 수정 (선택사항)
   - **전화번호**: 전화번호 수정 (선택사항)

3. **비밀번호 변경**:
   - 현재 비밀번호 입력
   - 새 비밀번호 입력 (8자 이상)
   - [비밀번호 변경] 버튼 클릭

### 활동 내역

프로필 페이지에서 작성한 게시글과 댓글 수를 빠르게 확인할 수 있습니다.

## 8. 알림 설정

### 알림 표시

- **알림 벨**: 상단 메뉴의 🔔 아이콘 클릭
- **알림 배지**: 읽지 않은 알림 수가 표시

### 알림 종류

- **게시글**: 새 게시글이 등록될 때
- **댓글**: 내 댓글에 답글이 달릴 때
- **좋아요**: 내 글에 좋아요가 눌릴 때
- **멘션**: 멘션(@사용자명) 사용 시

### 알림 관리

- **읽음 표시**: 알림 클릭 시 자동으로 읽음 처리
- **알림 삭제**: 이전 알림 목록은 유지
- **상세 보기**: 알림 클릭 시 관련 페이지로 이동

## 9. 다크 모드

### 다크 모드 사용법

1. **토글 버튼**: 상단 메뉴의 ☀️/🌙 버튼 클릭
2. **자동 저장**: 선택한 모드가 브라우저에 저장됨

### 다크 모드 특징

- 눈이 편안한 어두운 테마
- 더 적은 화면 밝기
- 높은 대비율 유지
- 모든 페이지에서 동일하게 적용

## 10. 비밀번호 재설정

### 비밀번호 재설정 방법

1. **로그인 페이지**: [비밀번호 찾기] 링크 클릭
2. **이메일 입력**: 가입 시 등록한 이메일 주소 입력
3. **재설정 링크 수신**: 이메일로 비밀번호 재설정 링크 수신

### 재설정 절차

1. 재설정 링크 클릭
2. 새 비밀번호 입력 (8자 이상)
3. [비밀번호 변경] 버튼 클릭
4. 로그인 페이지로 이동

### 보안 팁

- 주기적으로 비밀번호 변경 권장
- 같은 비밀번호는 사용하지 마세요
- 공용 컴퓨터에서 로그인하지 마세요

## 11. 이용 정책 및 주의사항

### 로그인 관련 알림

**Q: 로그인 후 화면 변화가 없어요.**
A: 페이지를 새로고침(F5)해주세요. 로그인 성공 후 페이지가 자동으로 리다이렉트되어야 합니다.

**Q: 관리자 링크가 안 보여요.**
A: 관리자 계정으로 로그인해야만 관리자 링크가 표시됩니다.
- **아이디**: `admin`
- **비밀번호**: `admin123`

### 이용 정책

1. **게시물 게시**:
   - 타인에게 불쾌감을 주는 내용 금지
   - 개인정보(주민등) 보호
   - 허위 사실 유포 금지
   - 스팸링 금지

2. **저작권**:
   - 타인의 저작물 무단 도용 금지
   - 출처 표시 필수 (링크 또는 인용)

3. **커뮤니티**:
   - 상호 존중하는 태도 유지
   - 비방어 사용

### 주의사항

1. **비밀번호**:
   - 비밀번호는 관리자도 알 수 없습니다
   - 재설정만 가능하며, 원본 비밀번호로는 복구할 수 없습니다

2. **삭제**:
   - 게시글/댓글 삭제 후 복구 불가
   - 회원 탈퇴 후 데이터는 보관 기간 동안만 유지

3. **관리자**:
   - 사용자 정지/탈퇴 가능
   - 게시글 강제 이동/삭제/수정 권한
   - 부적절한 게시물 삭제

이용 중 문제가 있거나 문의사항이 있다면 아래 연락처로 문의해주세요.

## 💡 자주 묻는 질문 (FAQ)

### 회원 관련

**Q: 비밀번호를 잊어버렸어요.**
A: 로그인 페이지의 [비밀번호 찾기] 기능을 이용하여 재설정하세요.

**Q: 이메일을 변경하고 싶어요.**
A: 프로필 페이지에서 이메일 주소를 변경할 수 있습니다.

**Q: 회원 탈퇴하고 싶어요.**
A: 현재 기능은 제공되지 않습니다. 관리자에게 문의하세요.

**Q: 아이디를 변경하고 싶어요.**
A: 현재 기능은 제공되지 않습니다. 새로 가입해주세요.

### 게시글 관련

**Q: 게시글 수정/삭제는 언제까지 가능한가요?**
A: 게시글 작성 후 언제든지 수정/삭제할 수 있습니다.

**Q: 첨부 파일 제한이 있나요?**
A: 이미지는 최대 5MB, 파일당 최대 5MB입니다. 관리자가 설정할 수 있습니다.

**Q: 비밀글은 어떻게 작성하나요?**
A: 글쓰기 시 [비밀글] 체크하면 됩니다. 로그인한 사용자와 관리자만 읽을 수 있습니다.

### 기술 문제

**Q: 에디터가 표시되지 않아요.**
A: 브라우저를 새로고침해주세요. 최신 버전의 Chrome, Firefox, Safari, Edge를 권장합니다.

**Q: 모바일에서 이용 가능한가요?**
A: 네, 반응형 웹사이트로 최적화되어 있습니다.
